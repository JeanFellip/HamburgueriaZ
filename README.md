# 🍔 HamburgueriaZ

Aplicativo Android desenvolvido em Java como projeto acadêmico.

## 📌 Descrição
O aplicativo HamburgueriaZ permite simular o registro de pedidos de uma hamburgueria fictícia, possibilitando a inserção do nome do cliente, escolha da quantidade de lanches, seleção de adicionais e envio do pedido por e-mail.

## ⚙️ Funcionalidades
- Inserção do nome do cliente
- Controle de quantidade de lanches
- Seleção de adicionais (Bacon, Queijo e Onion Rings)
- Cálculo automático do valor total
- Exibição do resumo do pedido
- Envio do pedido por e-mail (Intent)

## 🛠️ Tecnologias Utilizadas
- Java
- Android Studio
- XML
- Git e GitHub
